# Copilot Migration Playbooks

A curated collection of **real-world migration playbooks** using **GitHub Copilot**
for large-scale refactors, framework upgrades, and modernization projects.

This repository focuses on **how developers actually migrate production systems** 
step by step, safely, and incrementally.

---

## 🔧 What You’ll Find Here

- Java & Spring Boot migrations
- Frontend framework upgrades (React, Next.js, TypeScript)
- Backend and API modernizations
- Database and ORM migrations
- Copilot prompts for bulk refactors and validation

---

## 📂 Migration Categories

### ☕ Java
- Spring Boot 2 → 3 (Jakarta EE)
- Java 8 → Java 17

### 🌐 Frontend
- JavaScript → TypeScript
- Next.js Pages Router → App Router
- React Router v5 → v6

### ⚙️ Backend
- REST API → GraphQL
- Node.js CommonJS → ES Modules

### 🗄 Database
- Sequelize → Prisma
- Expand-and-Contract DB migrations
